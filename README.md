## 🌟 Overview

**PDF Reader Android** is built to render complex, multi-hundred-page technical manuals, vector diagrams, and forms with zero lag. Featuring asynchronous page rasterization and intelligent thumbnail pre-caching, it opens massive PDF files instantaneously without consuming excessive device RAM.

---

## ✨ Key Features

- **Instant Document Rasterization**: Multi-threaded page rendering leveraging native rendering pipelines.
- **Night Reading Mode**: High-contrast inverted color matrix and sepia filter for comfortable night reading.
- **Bookmark & Search**: Instant full-text search with keyword highlighting and persistent reading bookmarks.
- **Document Scanner Integration**: Digitize physical receipts and notes directly into searchable PDF documents.
